# Sơn Tinh — mẫu vector

Bản diễn giải sáng tạo theo mẫu người giản lược người dùng vừa chọn. Không dùng mô hình sinh ảnh, không tự động vector hóa, không tuyên bố phục dựng trang phục lịch sử.

`preview.png` là ảnh nền trắng; `preview_transparent.png` có alpha. `son_tinh.drawing.json` mở bằng Bàn vẽ Studio; gồm lớp nhân vật và lớp núi/đá độc lập. `studio_editor.png` là ảnh chụp widget thực. Nhân vật giữ trạng thái chờ xem, không tự ghi đạt QC hoặc đổi mẫu chính Mỏ Đen.

Tái dựng: `tools/draw_son_tinh_sample.py` dùng API đường nét và renderer Studio.
